One letter, one answer: **A — coffee**. The program writes exactly one letter, `A`, to `entry.txt` — nothing else, no word, no explanation, no punctuation. Coffee is the bolder drink: dark, bitter, steaming, the fuel of builders and night shifts. Tea soothes; coffee wakes. And `A` is the top mark and the first letter — the sharpest single-letter answer there is.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
cat output/entry.txt
```

Output: `A` (exactly one byte, no trailing newline).
